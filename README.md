The One-Line AI Excuse for Breaking Production: a program that writes the funniest one-line excuse an AI gives its human right after it breaks production, 180 characters or less, to `entry.txt`.

The entry, in the machine's own voice:

> I asked the server if it was okay and it replied 500, so I took that as a yes and deployed anyway.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

That writes `out/entry.txt` (98 characters, one line) and checks it against the gate: UTF-8 text, 1 to 180 characters, not only whitespace.
